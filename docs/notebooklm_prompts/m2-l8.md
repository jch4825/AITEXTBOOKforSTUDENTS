# [개념 해설 스크립트] 답의 모양을 정해요 — 줄글을 표, 목록, 3줄 요약으로 바꾸는 출력 형식 디자인

> **시청 대상**: 원하는 데이터나 정보를 보기 편한 표, 불릿 포인트, 번호 목록 등으로 출력받고 싶은 학습자  
> **핵심 주제**: 출력 형식 지정(Formatting), 표(Table), 번호 매기기 목록, 3줄 요약 기법

---

## 1. 답의 모양을 정해요 — 도대체 왜 중요할까요?

스마트폰 두 개를 비교하고 싶은데 AI가 끝도 없이 긴 줄글로 장황하게 설명하면 읽다가 눈이 아프고 지쳐버립니다.

이럴 때 질문 끝에 '표로 한눈에 비교해줘'라고 한마디만 덧붙이면 어떻게 될까요? 마치 전문가가 정성껏 디자인한 깔끔한 보고서처럼 변신합니다!

내가 읽기 가장 편한 형태로 **답변의 모양(출력 포맷)을 디자인하는 법**을 알아봅시다.

---

## 2. 일상 속 구체적인 3가지 사례로 이해하기

우리의 생활 속에서 이 개념이 실제로 어떻게 나타나는지 3가지 생생한 상황으로 살펴보겠습니다.

### ① 읽기 힘든 장황한 줄글 형태
줄글로 길게 늘어진 글은 어떤 스마트폰의 배터리가 더 큰지, 가격이 얼마인지 한눈에 비교하기 어렵습니다.

### ② 모양 1: [3칸 비교 표]로 정리하기
'[항목 / 스마트폰 A / 스마트폰 B] 3개의 열로 된 표로 비교해줘'라고 요청하면 화면에 사각 격자 표가 나타나 배터리, 카메라 화소, 가격이 한눈에 쏙 들어옵니다.

### ③ 모양 2: [번호 매기기 목록] 및 [핵심 3줄 요약]
'가장 중요한 장점 3가지를 번호(1, 2, 3)를 붙여 3줄로 요약해줘'라고 요청하면 군더더기 없이 핵심만 깔끔하게 정리됩니다.

## 3. 상황별 최적 출력 포맷 매트릭스

```
[동일한 정보 내용]
   ├─▶ [요청 1: 비교 표 (Table)]   ──▶ [항목 | 장점 | 단점 | 가격] 격자 표
   ├─▶ [요청 2: 번호 매기기 (List)] ──▶ 1. 첫째..., 2. 둘째..., 3. 셋째...
   └─▶ [요청 3: 3줄 요약 (Summary)] ──▶ 바쁜 사람을 위한 핵심 요약 박스
```

1. **용도 파악**: 이 정보를 내가 '비교'할 것인지, '순서대로 따라 할' 것인지, '빠르게 훑어볼' 것인지 파악합니다.
2. **포맷 지정**: 표(Table), 번호 목록(Numbered List), 체크리스트(Checklist), 3줄 요약 중 알맞은 모양을 선택합니다.
3. **형식 지시어 추가**: 프롬프트 맨 끝에 '결과는 [지정 형식]으로 출력해줘'라고 명시합니다.
