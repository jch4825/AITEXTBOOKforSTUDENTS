# [개념 해설 스크립트] AI가 다르게 알아들었을 때 — AI가 엉뚱한 오해를 했을 때 — 원인 찾기와 스마트한 재요청

> **시청 대상**: AI가 내 의도와 전혀 다른 답변을 내놓았을 때 당황하지 않고 원인을 찾아 수정하는 법을 배우고 싶은 학습자  
> **핵심 주제**: 의사소통 오류 분석, 모호한 어휘 교정, 오해 수정 프롬프트, 맥락 보완

---

## 1. AI가 다르게 알아들었을 때 — 도대체 왜 중요할까요?

'배 그리는 법 알려줘'라고 했더니, 나는 가을에 먹는 달콤하고 노란 과일 배를 원했는데 AI가 바다에 둥둥 떠다니는 거대한 유람선 배를 그리는 법을 설명하기 시작했습니다!

AI가 엉뚱하게 오해했을 때 화를 내거나 포기하지 않고 차분하게 바로잡는 비결을 알아봅시다.

말이 통하지 않을 때 문제를 해결하는 스마트한 소통의 기술입니다.

---

## 2. 일상 속 구체적인 3가지 사례로 이해하기

우리의 생활 속에서 이 개념이 실제로 어떻게 나타나는지 3가지 생생한 상황으로 살펴보겠습니다.

### ① 동음이의어의 오해
'배(Fruit / Ship)', '눈(Eye / Snow)', '다리(Leg / Bridge)', '밤(Night / Chestnut)'처럼 여러 가지 뜻을 가진 단어를 혼자 쓰면 AI가 엉뚱한 뜻으로 착각할 수 있습니다.

### ② 내 질문 속 오해 원인 찾기
내가 '먹는 과일'이라는 구체적 맥락을 쏙 빼놓고 그냥 '배'라고만 썼다는 사실을 침착하게 발견합니다.

### ③ 친절하고 명확하게 수정 재요청하기
'바다의 배가 아니라 가을에 먹는 달콤하고 노란 과일 배를 그리는 순서를 3단계로 알려줘'라고 맥락을 보충하여 다시 요청합니다.
- **결과**: AI가 '아! 과일 배군요!'라며 동그란 열매와 꼭지 그리는 법을 정확하게 설명합니다.

## 3. 오해 수정 3단계 리셋 프로토콜

```
[AI의 엉뚱한 답변 발견: 유람선 배 설명]
        ▼
[내 질문 속 모호한 단어 및 빠진 맥락 진단]
        ▼
[구체적인 수식어와 의도를 보충하여 재요청: '과일 배']
        ▼
[내가 원하던 완벽한 맞춤 답변 획득!]
```

1. **오류 진단**: AI의 답변을 보고 어디서 오해가 생겼는지 단어를 확인합니다.
2. **맥락 보충**: 여러 뜻을 가진 단어에 구체적인 수식어(먹는, 타는 등)를 붙입니다.
3. **재전송**: 차분하게 다시 요청하여 올바른 궤도로 되돌립니다.

## 4. 친구 사이의 말실수 바로잡기

* 친구가 내 말을 오해했을 때 '아니 그게 아니라 이런 뜻이야!'라고 다시 설명하듯, AI에게도 차분하게 다시 설명해 주면 됩니다.
* 대화가 어긋났을 때 침착하게 맥락을 다시 잡는 능력이 훌륭한 소통 능력입니다.

### ⚠️ 꼭 기억해야 할 흔한 오해와 진실
- **AI가 한 번 오해하면 그 대화창은 고장 난 것이니 버려야 한다? (X)**: 진실: 잘못 알아들은 부분을 짚어주며 대화를 이어갈 때 AI가 이전 맥락을 바탕으로 더욱 정확하게 수정합니다.
- **AI가 못 알아들은 것은 내 지능이 부족해서다? (X)**: 진실: 사람과 컴퓨터의 언어 소통에서 생기는 자연스러운 현상이므로 표현을 조금만 구체화하면 됩니다.
