# [개념 해설 스크립트] 분명하고 존중 있게 부탁하기 — AI와 대화할 때도 매너가 필요한 이유 — 디지털 에티켓

> **시청 대상**: 바르고 고운 언어 습관이 AI의 답변 품질과 자신의 디지털 인성에 미치는 영향을 이해하고 싶은 학습자  
> **핵심 주제**: 디지털 소통 에티켓, 명확하고 단정한 언어 사용, 비속어 지양과 올바른 프롬프팅

---

## 1. 분명하고 존중 있게 부탁하기 — 도대체 왜 중요할까요?

'어차피 감정도 없는 기계인데 욕설이나 거친 반말을 섞어 쓰면 어때?'라고 생각하는 사람이 있을 수 있습니다.

하지만 AI에게 욕설이나 거친 말을 쓰면 AI의 안전 필터가 작동하여 답변을 거부하거나 엉뚱한 답변을 낼 확률이 높아집니다.

더 놀라운 사실은, **단정하고 명확한 말을 쓸 때 AI도 가장 똑똑하고 품격 있는 답변**을 내놓는다는 것입니다!

---

## 2. 일상 속 구체적인 3가지 사례로 이해하기

우리의 생활 속에서 이 개념이 실제로 어떻게 나타나는지 3가지 생생한 상황으로 살펴보겠습니다.

### ① 거칠고 무례한 질문의 결과
'야, 이거 당장 써내놔라 멍청아'처럼 거칠게 말하면 AI가 질문의 핵심 맥락을 놓치거나 무성의하고 엉뚱한 답을 낼 수 있습니다.

### ② 분명하고 정중한 질문의 마법
'~에 대해 초등학생이 이해하기 쉽게 3가지로 정리해 주시겠어요?'처럼 명확하고 단정한 언어를 쓸 때 AI는 최고의 문장 생성 능력을 발휘합니다.

### ③ 내 언어 습관과 인성 지키기
AI를 대하는 말투는 결국 현실에서 친구와 가족을 대하는 나의 평소 언어 습관으로 이어집니다. 화면 앞에서도 품격 있는 언어를 사용하는 사람이 진짜 멋진 디지털 시민입니다.

---

## 3. 단정한 언어와 AI 답변 품질의 상관관계

```
[거칠고 모호한 욕설/비속어] ──▶ 안전 필터 오작동 / 맥락 왜곡 / 조잡한 답변
[단정하고 명확하며 정중한 요청] ──▶ 정확한 문맥 분석 / 품격 있고 정교한 최상의 답변!
```

1. **정확한 언어화**: 감정적인 비속어를 빼고 표준어와 명확한 어휘로 원하는 바를 작성합니다.
2. **안전성 확보**: 시스템 필터와의 불필요한 충돌을 방지합니다.
3. **품격 있는 결과**: 정중하고 논리적인 질문에 걸맞은 높은 수준의 답변을 얻습니다.

## 4. 거울 효과 (Mirror Effect)

* 우리가 거울을 향해 웃으면 거울 속 얼굴도 웃듯, AI에게 단정하고 맑은 언어를 건넬 때 가장 맑고 똑똑한 답변이 돌아옵니다.

### ⚠️ 꼭 기억해야 할 흔한 오해와 진실
- **AI는 기계니까 아무렇게나 막 대해도 내 인성에는 아무 영향이 없다? (X)**: AI와 나누는 대화 습관은 결국 일상 언어 습관으로 굳어지므로, 바른 언어를 쓰는 것이 나 자신에게 가장 좋습니다.
