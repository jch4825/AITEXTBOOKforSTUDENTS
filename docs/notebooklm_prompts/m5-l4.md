# [개념 해설 스크립트] 무엇부터 할지 기준으로 정하기 — 우선순위의 마법 — 중요도와 마감일로 첫 번째 할 일 고르기

> **시청 대상**: 할 일이 쏟아질 때 무엇을 먼저 해야 할지 명확한 기준으로 우선순위를 정하고 싶은 학습자  
> **핵심 주제**: 우선순위 결정(Prioritization), 긴급도 vs 중요도, 선택과 집중, 아이젠하워 매트릭스

---

## 1. 무엇부터 할지 기준으로 정하기 — 도대체 왜 중요할까요?

오늘 할 일이 5가지나 있습니다: '내일 아침까지 내야 하는 수학 숙제', '다음 주에 있을 미술 준비물 사기', '방 청소', '게임 일일 퀘스트', '친구에게 생일 축하 문자 보내기'.

머릿속이 복잡해서 멍하니 앉아있다면 무엇부터 해야 할까요?

이럴 때는 **'마감일(긴급도)'**과 **'내 삶에 미치는 영향(중요도)'** 2가지 기준을 세워 1등부터 줄을 세워야 합니다! 우선순위의 마법을 시작해 봅시다.

---

## 2. 일상 속 구체적인 3가지 사례로 이해하기

우리의 생활 속에서 이 개념이 실제로 어떻게 나타나는지 3가지 생생한 상황으로 살펴보겠습니다.

### ① 기준 1: '마감일이 오늘/내일인가?' (긴급도)
내일 1교시 수업 시간에 제출해야 하는 수학 숙제는 마감이 코앞에 닥친 가장 긴급한 1순위 과제입니다.

### ② 기준 2: '나의 성장과 약속에 얼마나 중요한가?' (중요도)
친구와의 생일 축하 약속 지키기, 다음 주 시험공부는 내 인간관계와 미래 성장에 매우 중요한 2순위입니다.

### ③ 기준 3: '나중에 여유 시간에 해도 되는가?' (여유 과제)
게임 일일 퀘스트나 다음 주 미술 붓 사기는 급하지도 않고 덜 중요한 3~4순위입니다. 중요한 일을 다 끝낸 뒤 홀가분한 마음으로 합니다.

## 3. 우선순위 4분면 아이젠하워 매트릭스

```
┌────────────────────────────┬────────────────────────────┐
│ 🚨 1순위: 마감 급함 + 중요함 │ ⭐ 2순위: 마감 여유 + 중요함 │
│ (내일 제출 수학 숙제)      │ (시험공부, 운동, 독서)     │
│ ──▶ 지금 당장 집중 실행!    │ ──▶ 매일 조금씩 계획 실행! │
├────────────────────────────┼────────────────────────────┤
│ ☕ 3순위: 마감 급함 + 덜중요 │ 🎮 4순위: 마감 없음 + 덜중요 │
│ (친구 문자 답장)           │ (게임 레벨업, 만화책)      │
│ ──▶ 빠르게 처리!           │ ──▶ 여유 시간에 휴식으로!  │
└────────────────────────────┴────────────────────────────┘
```

1. **목록 나열**: 오늘 해야 할 모든 일을 종이에 적습니다.
2. **4분면 분류**: 마감일(긴급도)과 가치(중요도) 기준으로 항목을 4개 방으로 나눕니다.
3. **1순위 단독 몰입**: 1순위 과제 딱 하나만 책상에 올려두고 스마트폰을 끈 채 끝장냅니다.

## 4. 항아리에 큰 돌과 모래 채우기

* 항아리에 모래(자잘한 놀이, 게임)를 먼저 가득 채우면 큰 돌(중요한 숙제, 공부)이 들어갈 자리가 없지만, 큰 돌을 먼저 넣으면 그 틈새로 모래도 다 들어갑니다.
* 중요한 1순위 일을 먼저 끝내야 마음 편하게 자유 시간을 만끽할 수 있습니다.

### ⚠️ 꼭 기억해야 할 흔한 오해와 진실
- **내가 제일 좋아하고 쉬운 놀이부터 무조건 먼저 한다? (X)**: 진실: 쉬운 일만 하다 보면 밤 11시에 울면서 숙제를 하게 됩니다. 1순위 숙제를 먼저 끝내야 진정한 자유가 옵니다.
- **할 일이 10개면 10개 모두 1순위로 중요할 수 있다? (X)**: 진실: 모든 것이 1순위라면 우선순위가 없는 것과 같습니다. 반드시 칼같이 1등, 2등을 골라내야 합니다.
