# [개념 해설 스크립트] 요청 공동 제작소 — 완벽한 답변을 이끌어내는 4가지 프롬프트 조립법

> **시청 대상**: 프롬프트의 4대 핵심 요소(역할, 상황, 임무, 조건)를 이해하고 직접 조립하고 싶은 학습자  
> **핵심 주제**: 프롬프트 엔지니어링 4요소(Role, Context, Task, Constraint), 체계적 요청 설계

---

## 1. 요청 공동 제작소 — 도대체 왜 중요할까요?

최고급 레스토랑에서 맛있는 파스타를 요리하려면 셰프에게 정확한 레시피와 주문이 들어가야 하듯이, AI에게 최고의 답변을 얻으려면 **4가지 핵심 블록**을 조립해야 합니다.

이 4가지 블록만 알면 여러분도 오늘부터 세상에서 가장 똑똑하게 AI를 지휘하는 **'프롬프트 마스터'**가 될 수 있습니다!

---

## 2. 일상 속 구체적인 3가지 사례로 이해하기

우리의 생활 속에서 이 개념이 실제로 어떻게 나타나는지 3가지 생생한 상황으로 살펴보겠습니다.

### ① 1번 블록: 역할(Role) 주기
'너는 20년 동안 학생들에게 우주를 가르쳐 온 친절한 천문학 박사님이야.' AI에게 전문 지식과 페르소나 가면을 씌워줍니다.

### ② 2번 블록: 상황(Context) 설명하기
'우리 학교에서 내일 우주 탐사 동아리 축제가 열려.' 어떤 배경에서 이 글이 필요한지 맥락을 제공합니다.

### ③ 3번 블록: 임무(Task)와 4번 블록: 조건(Constraint)
'[임무: 태양계 행성에 관한 3분 퀴즈 3문제 만들기] / [조건: 너무 어렵지 않은 4지 선다 객관식으로 만들고, 정답과 쉬운 해설은 맨 아래에 따로 적어줘].'

## 3. 프롬프트 4단 조립 공식 (R-C-T-C)

```
┌─────────────────────────────────────────────────────────────┐
│ 1. 역할 (Role)       : 20년 경력의 친절한 환경 동화 작가     │
│ 2. 상황 (Context)    : 초등학교 환경의 날 캠페인             │
│ 3. 임무 (Task)       : 바다거북이 쓰레기를 치우는 짧은 동화  │
│ 4. 조건 (Constraint) : 5문장 이내, 희망찬 결말, 쉬운 해요체  │
└─────────────────────────────────────────────────────────────┘
                               ▼
[모든 조건이 완벽하게 통제된 최상의 맞춤형 결과물 탄생!]
```

1. **역할(Role)**: AI가 취해야 할 관점과 전문성 수준을 정의합니다.
2. **상황(Context)**: 문제가 발생한 배경과 필요한 이유를 설명합니다.
3. **임무(Task)**: AI가 구체적으로 완수해야 할 핵심 작업을 명시합니다.
4. **조건(Constraint)**: 분량, 어조, 형식, 금지 사항 등 지켜야 할 제약 규칙을 지정합니다.

## 4. 대충 던지는 심부름 vs 꼼꼼한 레시피 주문서

* '알아서 맛있는 거 해와'라고 하면 주방장이 당황하지만, 재료와 굽기, 소스를 지정한 꼼꼼한 주문서를 주면 완벽한 요리가 나오는 것과 같습니다.
