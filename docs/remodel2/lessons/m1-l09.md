- aiRole(참고): 도구마다 받는 입력과 만드는 결과가 다르다는 것을 문답으로

## 4. 각본 리라이트 (visualNovel)
- `seasonTag: '[아이미가 왔다 · 9화] 도구 고르기 대작전',`
- `nextEpisodeHook: '다음 시간 — 체험회 음악을 골라요.',`
- 4장면 유지, imageSrc 그대로, knowledge 3장 수정 금지.

- 장면1 [서로 다른 세 가지 일]: 할 일 세 가지(요약·포스터·자막)를 대사로 나열.
  예) `윤아: "요약이랑 포스터랑 자막… 오늘 안에 셋 다 해야 해."`
- 장면2 [한 도구만 쓰자는 제안]: 진우의 성급한 제안(오개념).
  예) `진우: "글쓰기 AI가 제일 익숙하잖아. 셋 다 걔한테 맡기자!"`
- 장면3 [입력과 결과 비교]: 아이미가 상담원으로서 확인 질문을 던진다.
  예) `아이미: "질문이 있어요. 포스터를 만들려면 저는 무엇을 받아서 무엇을 만들어야 하나요?"`
  — 글·그림·소리 입력의 차이가 대화로 드러나게. 결론(도구 배정)은 내리지 않는다.
- 장면4 [배턴 터치 — 해결 금지]: '도구와 역할을 나눴다' 결말 삭제. 마지막 줄 취지:
  `아이미: "그럼 세 가지 일에 어떤 도구를 맡기실 건가요? 이유도 궁금해요!"`
  label·alt 미해결형으로 조정.

## 5. 선택지 반응 (각 choice에 `reaction` 추가)
firstAttempt:
- (정) 입력·결과 먼저 비교 — 예) `아이미: "좋은 순서예요! 일부터 정하면 도구는 따라와요."`
- (정) 개인정보·확인 가능성 — 윤아가 "얼굴 사진은 함부로 안 올려"라고 확인.
- (오) 유명 도구 하나로 전부 — 글쓰기 AI가 그림을 못 그려 멈추는 결과를 짧게.
- (오) 가장 빠른 도구만 — 결과 확인이 빠져 잘못 쓰일 뻔한 결과를 짧게.
transfer(여행 사진 설명): 정답은 도구 구분·안전 확인을 확인해 주고, 오답은
얼굴 사진 업로드·아무 도구나 쓰기의 결과를 인물이 짧게 보여 준다.
