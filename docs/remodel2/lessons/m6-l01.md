# m6-l1 지시서 — 조건에 맞는 장보기 [포맷 C · 미션 콜드오픈형]

먼저 읽기: `../04-HARNESS.md` → `../02-CHARACTERS.md` → 이 문서.
m6은 「나 혼자 일주일」 시즌(자립 챌린지 주간)이다 — 이 차시가 1화다.

## 1. 대상 파일 (이 밖은 수정 금지)
- `src/data/studios/m6/l01.ts`
- `src/data/lessons/m6.ts` — `m6-l1`의 `objective` 한 줄만
- §6의 검사 스크립트 해당 줄만

## 2. 학습목표 확정본 (한 글자도 바꾸지 말 것)
- **studentMission**:
  `아이미의 장보기 목록을 재고·가격·예산·알레르기와 비교해, 빼거나 바꿔서 안전한 목록으로 고쳐요.`
- teacherObjective(참고): AI 초안 목록을 실제 조건(보유·비용·건강)과 항목별로
  대조해 삭제·대체·수량 수정을 수행할 수 있다.
- aiRole(참고): 인원만 보고 목록을 만든다 — 바나나가 이미 있고 견과류
  알레르기가 있다는 것을 모른다.
- standards(참고): 주 [12인지06-01] · 부 [9인지06-01]

## 3. 포맷: C (미션 콜드오픈형)
`format: 'C',` 추가. (Wave 2에서 'AI 목록 그대로 담아 보기' 콜드오픈 —
실패 체험이 동기가 된다. ShoppingConditionCart 게임은 마무리 재도전.)

## 4. 각본 리라이트 (visualNovel)
- `seasonTag: '[나 혼자 일주일 · 1화] 첫 장보기',`
- `nextEpisodeHook: '다음 시간 — 계산대에서 얼마를 내야 할까?',`
- 4장면 유지, imageSrc 그대로, knowledge 3장 수정 금지.

- 장면1 [간식 준비 목적]: 챌린지 개막을 대사로.
  예) `아이미: "자립 챌린지 첫 과제, 장보기! 목록은 제가 3초 만에 만들었어요. 요거트, 사과, 바나나, 견과류!"`
- 장면2 [첫 장바구니]: 진우의 성급한 전부 담기.
  예) `진우: "아이미가 만들었으니 다 담자!"` — 윤아의 멈칫까지.
- 장면3 [실제 조건]: 조건 카드의 발견을 대사로.
  예) `윤아: "잠깐 — 바나나는 집에 있어. 그리고… 견과류 못 먹는 친구가 있잖아."`
  `아이미: "아, 그 정보는 저한테 없었어요!"` — 발견까지만.
- 장면4 [배턴 터치 — 해결 금지]: '최종 목록 완성' 결말 삭제. 마지막 줄 취지:
  `아이미: "조건을 알았으니 다시 정해요. 무엇을 빼고, 무엇을 바꾸시겠어요?"`
  label·alt 미해결형으로 조정.

## 5. 선택지 반응 (각 choice에 `reaction` 추가, 결과 제시형)
firstAttempt(현 선택지 구조 유지):
- 그대로 사기 계열 — 이미 있는 바나나가 두 배가 되고 위험한 견과류가 남는 결과
  (알레르기는 담백하게 — 공포 금지).
- 조건 대조·수정 계열 — 예) `아이미: "항목마다 조건을 대 보니 목록이 훨씬 안전해졌어요!"`
transfer: 같은 요령.

## 7. 이 차시의 하지 말 것
- 알레르기를 공포 소재로 쓰지 않는다 ('안전하지 않은 것'을 확인하는 절차로만).
- 아이미의 목록을 쓸모없는 것으로 그리지 않는다 (초안으로서 유용 — 조건 결합이
  학생 몫).
- 게임·knowledge·facts·artifact 수정 금지.
