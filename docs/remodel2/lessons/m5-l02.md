## 4. 각본 리라이트 (visualNovel)
- `seasonTag: '[체험회 D-6 · 2화] 너무 큰 일',`
- `nextEpisodeHook: '다음 시간 — 장식을 먼저 붙였더니 큰일.',`

- 장면2 [완성 모습 보기]: 윤아의 방법 — 완성 그림에서 거꾸로 찾기.
  예) `윤아: "완성된 모습부터 보자. 저 그림에 뭐가 들어 있지?"`
- 장면3 [누락과 중복]: 아이미 목록의 구멍 발견.
  예) `아이미: "목록 완성! …어? 왜 안내판이 두 번 있죠? 그리고 전원 확인이… 없네요?"`
  (아이미가 스스로 발견하게 해도 좋다 — 발견까지만.)
- 장면4 [배턴 터치 — 해결 금지]: '분해 보드 완성' 결말 삭제. 마지막 줄 취지:
  `윤아: "이 목록, 그대로 쓸 순 없겠어. 무엇을 빼고, 무엇을 더해야 할까?"`
  label·alt 미해결형으로 조정.
