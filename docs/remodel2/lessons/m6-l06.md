## 2. 학습목표 확정본 (한 글자도 바꾸지 말 것)
- **studentMission**:
  `재료·알레르기·도구·도움 조건을 확인해, 아이미의 요리 초안을 안전한 순서로 고쳐 조립해요.`
- teacherObjective(참고): AI 조리 초안을 건강·재고·도구·성인 도움 조건과 대조해
  위험 단계 제거·대체 재료 반영·순서 재구성을 수행할 수 있다.
- aiRole(참고): 조건을 모른 채 초안(칼 사용·알레르기 재료 포함)을 냈다가
  "제 첫 조리법은 조건을 몰랐던 초안"이라며 함께 고친다.
- standards(참고): 주 [12인지06-01] · 부 [9인지06-02]

## 4. 각본 리라이트 (visualNovel)
- `seasonTag: '[나 혼자 일주일 · 6화] 간식 초안 소동',`
- `nextEpisodeHook: '다음 시간 — 쉬는 시간이 사라졌다.',`
- 4장면 유지, imageSrc 그대로, knowledge 3장 수정 금지.
- 그림 카드 활동(실제 조리 아님) 설정과 "확인 전에는 실제 음식을 다루지 않는다"
  안전 계약을 반드시 유지.

- 장면1 [AI 음식 초안]: 예) `아이미: "과일 요거트 컵! 요거트, 키위, 바나나 — 그리고 과일은 칼로 잘라 주세요!"`
- 장면2 [첫 계획 카드]: 카드 배열의 즐거움 + 위화감의 씨앗.
  예) `윤아: "잠깐, 우리 칼 써도 되던가? 그리고 알레르기 확인은?"`
- 장면3 [건강과 도구 조건]: 조건 카드 4종(알레르기 확인 필요·키위 없음·칼 사용
  불가·교사가 준비한 대체) 발견까지만.
- 장면4 [배턴 터치 — 해결 금지]: '고친 계획 완성' 결말 삭제. 마지막 줄 취지:
  `아이미: "조건을 다 알았어요. 어느 단계를 빼고, 무엇으로 바꿔서, 어떤 순서로 만들까요?"`
  label·alt 미해결형으로 조정.

## 5. 선택지 반응 (각 choice에 `reaction` 추가, 결과 제시형)
firstAttempt:
- 조건 확인 없이 그대로 — 위험 단계(칼)와 미확인 재료가 남는 결과 (담백하게).
- 조건 확인 후 카드 수정 — 예) `민준 선생님: "확인 먼저, 음식은 그다음. 순서가 정확하구나."`
- AI에게 알레르기 추정 요청 — 아이미의 단호한 거절 ("건강 정보는 제가 추정하면
  안 돼요. 어른이 확인해야 해요.").
transfer(대체 과일도 없을 때): 같은 요령으로 3개 — '있는 것처럼 표시'에는 기록
거짓의 결과를 짧게.
