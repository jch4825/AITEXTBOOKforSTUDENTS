## 2. 학습목표 확정본 (한 글자도 바꾸지 말 것)

  `시끄러운 곳에서 아이미가 잘못 받아 적은 말을, 조건을 바꾸거나 다른 입력 방법을 골라 바르게 전해요.`
- teacherObjective(참고): 소음·거리·속도 조건이 음성 인식 결과를 바꾼다는 것을
  확인하고, 상황에 맞는 입력 방법(말·글자·그림)을 골라 정보를 바르게 전할 수 있다.
- aiRole(참고): 시끄러운 복도에서 "체험회에 놀러 오세요"를 "채소회 오이 사세요"로
  받아 적는다.
- standards(참고): 주 [9인지01-01] · 부 [12인지01-01]

## 4. 각본 리라이트 (visualNovel)
- `seasonTag: '[아이미가 왔다 · 5화] 채소회 오이 사건',`
- `nextEpisodeHook: '다음 시간 — 세모만 아는 분류기가 온대요.',`
- 4장면 유지, imageSrc 그대로, knowledge 3장 수정 금지.

'채소회 오이 사세요' 사건의 코미디를 대사로 살리고, 장면 4를 미해결로 바꾼다.

- 장면1 [시끄러운 복도]: 진우의 외침으로 시작.
  예) `진우: "체험회에 놀러 오세요!" — 복도는 친구들 소리로 가득했습니다.`
- 장면2 [달라진 글자]: 화면을 본 인물들의 반응 대사.
  예) `윤아: "잠깐, 화면에 '채소회 오이 사세요!'라고 적혔는데?"`
  `아이미: "제 귀에는 분명 그렇게 들렸어요!"`
- 장면3 [듣는 조건 바꾸기]: 윤아의 확인 질문으로 조건 실험을 연다
  (조용한 곳·마이크 거리·천천히 말하기 — 하나씩 바꾸는 과정).
- 장면4 [배턴 터치 — 해결 금지]: '편한 방법을 골랐다' 결말 삭제. 마지막 줄 취지:
  `윤아: "방법이 여러 가지네. 너라면 어떤 방법으로 안내를 바르게 전하겠어?"`
  label·alt 미해결형으로 조정.

## 5. 선택지 반응 (각 choice에 `reaction` 추가)
firstAttempt:
- (정) 조용한 곳에서 재입력 — 예) `아이미: "이제 또렷하게 들려요. '체험회에 놀러 오세요!' 맞지요?"`
- (정) 입력 조건 비교 — 윤아가 "조건을 바꾸니 결과가 달라지네"라고 확인.
- (오) 화면 글자 그대로 믿기 — 오이를 사러 가려는 진우를 윤아가 붙잡는 반응
  (결과 제시, 비난 금지).
- (오) 무작정 크게 소리치기 — 더 이상하게 적히는 결과를 짧게 보여 준다.
transfer(체육관 안내): 정답은 '재확인/다른 입력'의 결과를, 오답은 '잘못 적힌
글자만 믿고 이동'의 결과를 인물이 짧게 보여 준다.
