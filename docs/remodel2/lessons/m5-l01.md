# m5-l1 지시서 — 문제를 정확히 찾기 [포맷 A · 이야기 우선형]

먼저 읽기: `../04-HARNESS.md` → `../02-CHARACTERS.md` → 이 문서.
m5는 「체험회 D-7」 시즌이다 — 11개 차시가 D-7부터 D-1까지 이어지는 연속극이며,
이 차시가 그 1화다.

## 1. 대상 파일 (이 밖은 수정 금지)
- `src/data/studios/m5/l01.ts`
- `src/data/lessons/m5.ts` — `m5-l1`의 `objective` 한 줄만
- §6의 검사 스크립트 해당 줄만

## 2. 학습목표 확정본 (한 글자도 바꾸지 말 것)
- **studentMission**:
  `물품이 안 온 상황에서 지금 모습과 원하는 모습을 나눠 적고, 아이미와 함께 진짜 문제를 한 문장으로 만들어요.`
- teacherObjective(참고): 현재 상태와 목표 상태를 관찰 가능한 말로 구분하고,
  모르는 정보·필요한 도움을 표시해 문제를 한 문장으로 정의할 수 있다.
- aiRole(참고): "행사를 못 해"라는 막막함에서 확인할 정보와 지금 가능한 행동을
  분리하도록 돕는다.
- standards(참고): 주 [9인지05-01] · 부 [12인지05-01]

## 3. 포맷: A (이야기 우선형)
`format: 'A',` 추가. (시즌 오프닝 — 이야기가 전면.)

## 4. 각본 리라이트 (visualNovel)
- `seasonTag: '[체험회 D-7 · 1화] 오지 않은 물품',`
- `nextEpisodeHook: '다음 시간 — 이번엔 「부스를 설치해」라는 큰 일이 온다.',`
- 4장면 유지, imageSrc 그대로, knowledge 3장 수정 금지.
- **주의**: 현재 m5 각본은 challenge 슬롯이 교육학 강의문이다(예: "막막한 감정과
  해결할 문제를 구분하면…"). 전부 같은 드라마의 풍부한 버전으로 다시 쓴다.

- 장면1 [빈 설치 공간]: 사건의 충격을 대사로.
  예) `진우: "…없어. 책상도 안내판도 안 왔어. 행사를 못 해!"`
- 장면2 [현재와 목표]: 윤아의 확인 질문이 막막함을 쪼갠다.
  예) `윤아: "잠깐. '못 해'가 아니라 — 지금 뭐가 있고, 언제까지 뭐가 필요한 거야?"`
- 장면3 [정보 확인]: 아는 것/모르는 것의 발견.
  예) `아이미: "제가 아는 것: 목표는 오후 3시 설치. 제가 모르는 것: 배송이 언제 오는지. 이건 사람이 확인해야 해요."`
- 장면4 [배턴 터치 — 해결 금지]: '문제 정의 카드 완성' 결말 삭제. 마지막 줄 취지:
  `윤아: "이제 한 문장으로 말해 보자. 우리의 진짜 문제는 — 뭘까?"`
  label·alt 미해결형으로 조정.

## 5. 선택지 반응 (각 choice에 `reaction` 추가, 결과 제시형)
firstAttempt:
- 확인 없이 바로 재구매 — 오후에 물품이 두 배로 도착하는 결과 (유머, 낭비).
- 현재·목표·정보·행동 나누기 — 예) `아이미: "나누고 나니 제가 도울 곳이 보여요!"`
- 행사 전체 취소 — 확인 한 번이면 살릴 수 있었음이 드러나는 결과 (부드럽게).
transfer(색종이 부족): 같은 요령으로 3개 — '누가 잘못했나 찾기'에는 문제 해결이
멈추는 결과.

## 7. 이 차시의 하지 말 것
- '행사를 못 해' 감정을 비웃지 않는다 (막막함은 정당한 감정 — 그다음이 문제 정의).
- challenge 카피에 강의문을 남기지 않는다 (이 단원의 1차 실패 지점).
- knowledge·facts·artifact 수정 금지. `수업용 연습 예시` 안전 문구
  (PREPARED_PROBLEM_NOTE 관련 데이터)를 건드리지 않는다.
