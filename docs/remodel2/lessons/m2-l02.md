## 2. 학습목표 확정본 (한 글자도 바꾸지 말 것)
- **studentMission**:
  `한 문장에 섞인 여러 부탁을 하나씩 나누고, 마감이 빠른 것부터 아이미에게 차례로 부탁해요.`
- teacherObjective(참고): 복합 요청을 목적 단위로 분해하고 마감·의존 관계를
  기준으로 요청 순서를 정할 수 있다.
- aiRole(참고): 세 부탁이 섞인 문장을 받으면 결과도 섞어 내놓는다.
- standards(참고): 주 [9인지02-02] · 부 [12인지02-02]

## 4. 각본 리라이트 (visualNovel)
- `seasonTag: '[부탁의 달인 · 2화] 세 부탁이 한 문장에',`
- `nextEpisodeHook: '다음 시간 — 아무거나의 함정.',`
- 4장면 유지, imageSrc 그대로, knowledge 3장 수정 금지.

- 장면1 [긴 요청]: 진우의 성급한 몰아넣기 대사로.
  예) `진우: "아이미야! 안내문 쓰고 간식 고르고 음악도 추천해 줘. 한 번에!"`
- 장면2 [뒤엉킨 결과]: 섞인 결과의 코미디. 예) `아이미: "완성! 안내문 중간에 팝콘과 신나는 폴카를 넣어 두었어요!"`
- 장면3 [목적 카드 나누기]: 윤아의 확인 질문으로 분해를 연다
  ("가장 급한 게 뭐지? 간식 수는 언제 알 수 있지?") — 나누는 발견까지만,
  순서 확정은 하지 않는다.
- 장면4 [배턴 터치 — 해결 금지]: '두 번에 나누자 분명해졌다' 결말 삭제.
  마지막 줄 취지:
  `윤아: "카드 세 장이 됐어. 그럼 무엇부터, 어떤 차례로 부탁할까?"`
  label·alt 미해결형으로 조정.

## 5. 선택지 반응 (각 choice에 `reaction` 추가, 결과 제시형)
firstAttempt:
- 더 짧은 한 문장에 다시 — 또 섞여 나오는 결과를 짧게 (줄이기 ≠ 나누기).
- 마감 빠른 안내문부터 — 예) `아이미: "안내문 하나만요? 좋아요, 이건 자신 있어요!"`
- 순서 없이 음악부터 — 마감인 안내문이 늦어질 뻔한 결과를 윤아가 짚는 반응.
transfer(여행 준비 나누기): 같은 요령으로 3개.
