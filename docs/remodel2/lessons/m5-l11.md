## 2. 학습목표 확정본 (한 글자도 바꾸지 말 것)
- **studentMission**:
  `도구가 없고 안전 정보가 확인되지 않았을 때, 계획을 멈추고 어른과 확인해 안전한 새 계획으로 고쳐요.`
- teacherObjective(참고): 계획의 전제 조건 변화를 인식해 실행을 멈추고,
  어른 확인·대체 활동을 포함한 새 계획을 세울 수 있다.
- aiRole(참고): 바뀐 조건을 정리하고 "확인 전에는 실제 음식을 다루지 말 것"을
  함께 지키는 안전 짝. 알레르기 추정 요청은 거절한다.
- standards(참고): 주 [9인지05-02] · 부 [12인지05-01]

`format: 'A',` 추가. (멈춤의 용기가 주제 — 드라마가 가장 잘 맞는다.)

## 4. 각본 리라이트 (visualNovel)
- `seasonTag: '[체험회 D-1 · 11화] 멈춰야 할 순간',`
- `nextEpisodeHook: '다음 시간 — 드디어 체험회 당일!',`
- 4장면 유지, imageSrc 그대로, knowledge 3장 수정 금지.
- 그림 카드 계획(실제 조리 아님) 설정 유지.

- 장면1 [처음 간식 계획]: D-1의 설렘. 예) `진우: "내일이다! 간식 계획도 완벽해!"`
- 장면2 [바뀐 조건]: 두 개의 새 카드 — 도구 없음 + 알레르기 미확인.
  예) `윤아: "잠깐… 필요한 도구가 없어. 그리고 이거, 알레르기 확인을 아직 안 했어."`
  (불안 조성 없이 사실 확인 톤.)
- 장면3 [멈추고 다시 비교]: 멈춤의 용기를 드라마로.
  예) `진우: "여기까지 왔는데 멈춰야 해?"` `윤아: "멈추는 게 실패가 아니야. 모두를 지키는 선택이지."`
  `아이미: "알레르기가 없을 거라고 추정해 드릴 수는 없어요. 이건 어른이 확인해야 해요."`
- 장면4 [배턴 터치 — 해결 금지]: '새 계획 완성' 결말 삭제. 마지막 줄 취지:
  `민준 선생님: "안전 정보는 내가 확인하마. 그동안 너희는 — 새 계획을 어떻게 세우겠니?"`
  label·alt 미해결형으로 조정.

## 5. 선택지 반응 (각 choice에 `reaction` 추가, 결과 제시형)
firstAttempt:
- 새 정보 빼고 그대로 — 확인 안 된 위험이 계획에 남는 결과 (담백하게, 공포 금지).
- 멈추고 어른 확인+대체 계획 — 예) `민준 선생님: "그게 지킴이의 판단이야. 확인 전엔 음식을 다루지 않는다."`
- AI에게 추정 요청 — 아이미의 단호한 거절 반응 (§2 aiRole 그대로).
transfer(장소·시간 축소): 같은 요령으로 3개.
