## 4. 각본 리라이트 (visualNovel)
- `seasonTag: '[안전 지킴이 · 2화] 취소됐대 소문',`
- `nextEpisodeHook: '다음 시간 — 도움을 구하다 정보가 너무 많이!',`
- 4장면 유지, imageSrc 그대로, knowledge 3장 수정 금지.

- 장면1 [누가 쓴지 모르는 글]: 소문의 등장 — 걱정되지만 전달을 멈추는 순간.
  예) `진우: "체험회 취소래! 빨리 다 알려야…"` `윤아: "잠깐! 누가 쓴 건지부터 보자."`
- 장면2 [세 자료]: 세 자료가 나란히 놓이는 장면 — 캡처(출처 불명), 지난달 공지,
  오늘 공식 공지.
- 장면3 [출처 기준]: 윤아의 확인 질문으로 기준 발견
  ("누가? 언제? 원래 글은 어디에?") — 표시까지만, 최종 선택은 하지 않는다.
- 장면4 [배턴 터치 — 해결 금지]: '확인해 알렸다' 결말 삭제. 마지막 줄 취지:
  `진우: "기준표는 다 채웠어. 그래서… 셋 중 뭘 믿어야 해?"`
  label·alt 미해결형으로 조정.

## 5. 선택지 반응 (각 choice에 `reaction` 추가, 결과 제시형)
firstAttempt:
- 출처 불명 캡처 — 처음 나온 곳을 찾을 수 없음이 드러나는 반응.
- 오늘 공식 공지 — 예) `윤아: "오늘 날짜, 담당 부서, 원문 링크. 세 가지가 다 있네."`
- 지난달 공지 — 학교 자료지만 다른 행사임이 드러나는 반응 (이름만으로는 부족).
transfer(준비물 변경 소식): 같은 요령으로 3개.
