- teacherObjective(참고): 단계 간 선행 조건·안전 조건을 근거로 순서를 구성하고
  모의 실행으로 검증·수정할 수 있다.
- aiRole(참고): 그럴듯한 추천 순서를 내놓지만 모의 실행에서 막히는 지점이
  드러난다 ("제 추천이 너무 빨랐네요").
- standards(참고): 주 [9인지05-02] · 부 [12인지05-02]

## 4. 각본 리라이트 (visualNovel)
- `seasonTag: '[체험회 D-6 · 3화] 막힌 전원선',`
- `nextEpisodeHook: '다음 시간 — 요청 세 개가 한꺼번에!',`
- 4장면 유지, imageSrc 그대로, knowledge 3장 수정 금지.
- 모의 설치판(실제 전기 아님) 설정을 반드시 유지한다.

- 장면1 [막힌 설치]: 진우의 성급한 장식 먼저.
  예) `진우: "예쁜 것부터! 장식 완료! …어? 전원선 놓을 자리가 없어."`
- 장면2 [앞 단계 이유]: 윤아의 확인 질문으로 '왜 먼저'의 발견.
  예) `윤아: "순서를 외우지 말고 이유를 찾자. 책상은 왜 장식보다 먼저야?"`
- 장면3 [모의 실행]: 아이미 추천 순서도 모의 실행에서 막히는 발견.
  예) `아이미: "제 추천대로 하면… 어라, 책상을 너무 일찍 고정해서 안전 확인이 어렵네요. 제 추천이 틀릴 수도 있군요!"`
- 장면4 [배턴 터치 — 해결 금지]: '절차표 완성' 결말 삭제. 마지막 줄 취지:
  `윤아: "이유는 다 찾았어. 이제 절차표를 조립하자 — 첫 칸에 무엇을 놓겠어?"`
  label·alt 미해결형으로 조정.
