## 4. 각본 리라이트 (visualNovel)
- `seasonTag: '[체험회 D-2 · 9화] 멈춘 프린터',`
- `nextEpisodeHook: '다음 시간 — 방문객이 자꾸 처음 화면으로.',`
- 4장면 유지, imageSrc 그대로, knowledge 3장 수정 금지.

- 장면1 [멈춘 방법]: D-2의 위기감을 대사로 (불안 아닌 긴장).
  예) `진우: "프린터가… 안 돼. 내일모레가 체험회인데 안내문을 못 뽑아!"`
- 장면2 [세 가지 대안]: 윤아의 전환 질문.
  예) `윤아: "목표는 '출력'이 아니라 '안내'야. 안내할 다른 길이 뭐가 있을까?"`
  — 손글씨·다른 프린터·화면 안내의 등장까지.
- 장면3 [같은 기준]: 아이미의 비교표 정리 — 각 대안의 장단이 보이는 데까지만.
- 장면4 [배턴 터치 — 해결 금지]: '조합 선택 완료' 결말 삭제. 마지막 줄 취지:
  `아이미: "비교표가 완성됐어요. 지금 조건에서 당신이라면 어느 길을 고르겠어요?"`
  label·alt 미해결형으로 조정.

짚는 반응.
