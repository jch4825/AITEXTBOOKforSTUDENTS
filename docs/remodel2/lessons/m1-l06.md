## 2. 학습목표 확정본 (한 글자도 바꾸지 말 것)

  `세모 카드만 잔뜩 배운 AI가 왜 자꾸 틀리는지 배움 상자를 확인하고, 자료를 골고루 바꿔 결과를 비교해요.`
- teacherObjective(참고): 학습 자료의 치우침이 AI 결과의 치우침을 만든다는 것을

- aiRole(참고): 세모 위주로 배운 탓에 세모 과자를 "찌그러진 동그라미"라고
  자신 있게 부른다.
- standards(참고): 주 [9인지01-01] · 부 [12인지01-01]

## 4. 각본 리라이트 (visualNovel)
- `seasonTag: '[아이미가 왔다 · 6화] 세모만 아는 분류기',`
- `nextEpisodeHook: '다음 시간 — 10페이지 안내문을 1초 만에?',`
- 4장면 유지, imageSrc 그대로, knowledge 3장 수정 금지.

**장면 순서의 의미를 재배열한다** (이미지 4장은 순서 그대로 두고 텍스트 의미만):
현재 장면3에서 이미 자료를 보완하고 장면4에서 결과까지 좋아진다(해결 완료).
새 구성은 '원인 발견까지'만 간다:

- 장면1 [모양 카드 상자]: 사건으로 시작 — 분류 AI가 자꾸 틀리는 장면.
  예) `진우: "이 AI, 동그라미도 세모래! 고장 났나 봐."`
- 장면2 [자꾸 세모라는 답]: 진우의 성급한 결론과 윤아의 확인 질문.
  예) `윤아: "고장일까? 이 AI가 뭘 보고 배웠는지부터 보자."`
- 장면3 [배움 상자 열기]: 상자 속 카드가 세모투성이임을 발견하는 대사
  (자료 보완은 아직 하지 않는다 — 발견까지만).
- 장면4 [배턴 터치 — 해결 금지]: '전후 비교로 좋아졌다' 결말 삭제. 마지막 줄 취지:
  `윤아: "원인은 찾았어. 그럼 상자를 어떻게 다시 채워야 할까?"`
  label·alt 미해결형으로 조정 (이미지의 '고르게 담긴 카드' 그림은 '이렇게 채우면
  어떨까?'라는 제안 프레임으로 재해석).

## 5. 선택지 반응 (각 choice에 `reaction` 추가)
firstAttempt:
- (정) 학습 데이터 조사 — 예) `아이미: "상자를 열어 볼까요? 배운 카드가 여기 다 있어요."`
- (정) 비율·다양성 확인 — 윤아가 카드 수를 세며 치우침을 확인하는 반응.
- (오) 기분 탓 — 아이미가 "저는 기분이 없어요. 배운 자료가 전부예요"라고 정정.
- (오) 쉬운 카드만 보여주기 — 문제가 그대로 남는 결과를 짧게 보여 준다.
transfer(분리배출 표지 AI): 정답은 '자료 보완+전후 비교'의 결과를, 오답은
'치우친 결과 방치'의 결과를 인물이 짧게 보여 준다.
