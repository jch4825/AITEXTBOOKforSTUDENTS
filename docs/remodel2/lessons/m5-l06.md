## 2. 학습목표 확정본 (한 글자도 바꾸지 말 것)
- **studentMission**:
  `아이미가 다르게 알아들은 까닭을 찾고, 개인정보 없이 필요한 단서만 더해 다시 요청해요.`
- teacherObjective(참고): AI의 추정과 제공 정보의 간극을 분석하고, 개인정보를
  제외한 필요 단서로 재요청한 뒤 외부 자료로 확인할 수 있다.
- aiRole(참고): "도서관 앞 부스"를 학교 밖 공공 도서관으로 추정한다 — 그리고
  학교명을 더하자고 제안했다가 더 안전한 단서를 함께 찾는다.
- standards(참고): 주 [9인지05-01] · 부 [9인지02-02]

## 4. 각본 리라이트 (visualNovel)
- `seasonTag: '[체험회 D-4 · 6화] 엉뚱한 도서관',`
- `nextEpisodeHook: '다음 시간 — 긴 설치 안내, 다 기억할 수 있을까.',`
- 4장면 유지, imageSrc 그대로, knowledge 3장 수정 금지.

- 장면1 [다른 장소]: 예) `진우: "도서관 앞 부스 알려 줘!"`
  `아이미: "안내 완료! 마을 도서관까지 걸어서 15분입니다!"` `진우: "…우리 학교 도서관인데?"`
- 장면2 [요청과 추정]: 원인 분석을 문답으로 — 자책도 AI 탓도 아닌 정보 간극.
  예) `윤아: "네 탓도 아이미 탓도 아니야. 요청에 '어느 건물'이 없었을 뿐이야."`
- 장면3 [안전한 단서]: 아이미의 제안과 더 안전한 선택.
  예) `아이미: "학교 이름을 알려 주시면…"` `윤아: "잠깐, 이름 없이도 돼. '지금 건물 안, 2층, 초록 표지 앞' — 이 정도면?"`
- 장면4 [배턴 터치 — 해결 금지]: '수정 경로 확인 완료' 결말 삭제. 마지막 줄 취지:
  `아이미: "다시 요청해 주세요. 이번엔 어떤 단서를 넣으시겠어요?"`
  label·alt 미해결형으로 조정.

## 5. 선택지 반응 (각 choice에 `reaction` 추가, 결과 제시형)
firstAttempt:
- 학교 이름+주소 전부 — 아이미가 "그 정보까지는 필요 없어요. 안전을 위해 빼요"
  라고 정중히 거절.
- 필요한 단서만 — 예) `아이미: "건물 안 2층 초록 표지! 이제 정확히 알겠어요."`
- 내 탓이라고만 — 원인 분석 없이는 다음에도 같은 일이 생김을 부드럽게 짚는 반응.
transfer(체육관 안 부스): 같은 요령으로 3개.
