## 4. 각본 리라이트 (visualNovel)
- `seasonTag: '[부탁의 달인 · 7화] 사라진 시간과 장소',`
- `nextEpisodeHook: '다음 시간 — 전부 긴 문단으로 나왔다!',`
- 4장면 유지, imageSrc 그대로, knowledge 3장 수정 금지.

- 장면1 [첫 안내]: 예) `진우: "너무 길고 어려워… 아이미야, 더 쉽게 고쳐 줘!"`
- 장면2 [정보 누락]: 예) `아이미: "쉽게 만들었어요!"` `윤아: "정말 쉬워졌네. 그런데… 몇 시에 어디로 오라는 거지?"`
- 장면3 [기준을 넣은 재요청]: 윤아의 확인 질문으로 '지킬 것/고칠 것' 분리 발견
  ("빠지면 안 되는 게 뭐였지?") — 발견까지만, 완성된 재요청문은 금지.
- 장면4 [배턴 터치 — 해결 금지]: '개선본 확인' 결말 삭제. 마지막 줄 취지:
  `아이미: "다시 고쳐 볼게요. 무엇은 꼭 남기고, 무엇을 바꿀까요?"`
  label·alt 미해결형으로 조정.

## 5. 선택지 반응 (각 choice에 `reaction` 추가, 결과 제시형)
firstAttempt:
- "아직 마음에 안 들어"만 — 아이미가 무엇을 고칠지 몰라 엉뚱한 곳을 바꾸는 결과.
- 지킬 사실+고칠 표현 — 예) `아이미: "시간과 장소는 그대로, 어려운 낱말만 바꾸라는 거군요. 확실해요!"`
- 빠진 채로 사용 — 시간을 몰라 헤매는 친구가 생기는 결과 1줄.
transfer(길지만 정확한 안내): 같은 요령으로 3개 — '무조건 짧게'에는 중요 내용
소실 결과, '전체 버리기'에는 정확한 정보까지 잃는 결과.
