# m1-l11 지시서 — 단원 마무리: 아이미 사용 설명서 [시즌 피날레]

먼저 읽기: `../04-HARNESS.md` → `../02-CHARACTERS.md` → 이 문서.
단원 마무리는 포맷 배정 대상이 아니다. **시즌 「아이미가 왔다」의 최종화** 연출만
더한다. 작업 범위가 매우 작다 — 그 이상 하지 않는다.

## 1. 대상 파일 (이 밖은 수정 금지)
- `src/data/modulePortfolios/m1.ts` — `closingStory`의 `copy` 문자열 3개만

## 2. 학습목표
**변경 없음.** lessons의 m1-l11 objective(`오늘은 새 AI 상황에서 입력·결과·확인할
점을 찾아 나만의 AI 사용 설명서를 완성해 봐요.`)는 이미 피날레(설명서 완성)와
일치한다. 계약 갱신도 없다.

## 3. 각본 리라이트 (closingStory copy 3개)
현재 카피는 서술체다. 시즌 최종화 톤(대사 중심 + 열 번의 사건 회상)으로 바꾼다.
id·label·imageSrc·alt 구조는 유지하고 copy 문자열만 교체한다.

- 장면1 [새 학생의 질문]: 하린이의 질문을 유지하되 최종화 프레임을 연다.
  예) `[아이미가 왔다 · 최종화] 새로 온 하린: "아이미의 답은 언제 믿어도 되고, 언제 다시 확인해야 해?" — 진우와 윤아는 서로를 마주 보았습니다.`
- 장면2 [열 번의 기록]: 지난 10화의 사건을 콜백한다 (급식 발표, 여우 사진,
  채소회 오이, 자장가 사건 중 2~3개를 짧게 호명).
  예) `진우: "무지개 떡볶이 사건 기억나? 자장가 사건도!" 윤아: "그때마다 우리가 뭘 확인했는지, 기록이 다 있어."`
- 장면3 [설명서 전달]: 완성 선언이 아니라 **학생에게 넘기는** 문장으로 끝낸다.
  예) `윤아: "이제 우리가 배운 걸 한 장에 모을 차례야. 하린이에게 줄 설명서, 너라면 어떤 내용부터 적겠어?"`

## 4. 하지 말 것
- title(`아이미 사용 설명서`)·crumb·kicker·artifactChoices·guideSections·
  transferPrompt·nextChoices 수정 금지 (계약·수집 연동).
- 이미지 3장 경로 수정 금지.
- 지난 화 콜백에 없는 사건을 지어내지 않는다 (m1-l01~l10 지시서의 시즌 자막
  제목만 콜백 소재로 쓴다).
