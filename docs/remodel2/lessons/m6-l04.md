## 2. 학습목표 확정본 (한 글자도 바꾸지 말 것)
- **studentMission**:
  `버스 번호·방향·정류장을 오늘 공지와 확인하고, 헷갈리면 타기 전에 안전하게 도움을 요청해요.`
- teacherObjective(참고): 노선 번호·방향·정류장·최신 공지를 대조해 탑승을
  판단하고, 불확실할 때 탑승 전 확인 질문을 수행할 수 있다.
- aiRole(참고): 평소 정보("12번 타면 돼요")를 말했다가 오늘 우회 공지 확인을
  권한다 — 일반 정보와 오늘 정보는 다르다.
- standards(참고): 주 [9인지06-01] · 부 [12인지06-01]

## 3. 포맷: B (실험 우선형)
`format: 'B',` 추가. (Wave 2에서 BusDirection 게임이 도입 실험.)

## 4. 각본 리라이트 (visualNovel)
- `seasonTag: '[나 혼자 일주일 · 4화] 12번과 21번',`
- `nextEpisodeHook: '다음 시간 — 「따뜻해요」만 믿어도 될까.',`
- 4장면 유지, imageSrc 그대로, knowledge 3장 수정 금지.
- 연습 정류장(수업용 화면) 설정 유지.

- 장면1 [비슷한 노선]: 예) `진우: "왔다! …어? 12번이야 21번이야? 숫자가 헷갈려."`
- 장면2 [오래된 일반 안내]: 예) `아이미: "평소에는 12번이면 돼요!"`
  `윤아: "잠깐 — 오늘 공지에 12번은 우회한대."` (평소 정보 vs 오늘 정보의 충돌.)
- 장면3 [방향과 공지 확인]: 확인 항목의 발견(번호→방향→정류장→오늘 공지) —
  체크 방법까지만.
- 장면4 [배턴 터치 — 해결 금지]: '직원 확인 완료' 결말 삭제. 마지막 줄 취지:
  `윤아: "공지가 복잡하네. 이럴 때 너라면 — 그냥 탈래, 아니면 누구에게 뭐라고 물어볼래?"`
  label·alt 미해결형으로 조정.

## 5. 선택지 반응 (각 choice에 `reaction` 추가, 결과 제시형)
firstAttempt:
- 비슷한 번호 먼저 온 버스 — 반대 방향으로 갈 뻔한 결과 (담백하게).
- 번호·방향·정류장·공지 확인 — 예) `아이미: "네 가지를 다 보셨네요. 오늘은 저보다 공지가 정확해요!"`
- AI 평소 답 우선 — 우회 공지를 놓치는 결과 + 아이미의 "오늘 공지를 우선하세요"
  정정.
transfer(지하철 반대 방향): 같은 요령으로 3개 — '사람 많은 쪽' 오답에는 군중이
근거가 아님을 짚는 반응.
