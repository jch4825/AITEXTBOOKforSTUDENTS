## 4. 각본 리라이트 (visualNovel)
- `seasonTag: '[아이미가 왔다 · 2화] 동아리방의 세 가지 도구',`
- `nextEpisodeHook: '다음 시간 — 아이미가 급식 메뉴를 발표한대요.',`
- 4장면 유지, imageSrc 그대로, knowledge 3장 수정 금지.

현재 각본은 윤아 혼자 관찰-분류-조사-정리를 끝내는 3인칭 서술이다.
아이미의 질문으로 여닫는 대화극으로 바꾼다.

- 장면1 [세 가지 도구]: 아이미가 문제를 연다.
  예) `아이미: "궁금한 게 있어요. 선풍기도, 자동문도, 음악 앱도 움직이는데… 저랑 뭐가 다른가요?"`
- 장면2 [첫 번째 분류]: 진우의 성급한 분류(오개념 체험).
  예) `진우: "간단해! 스스로 움직이면 전부 AI지!"` — 윤아가 갸웃하는 반응까지만.
- 장면3 [입력 신호 조사]: 윤아의 확인 질문으로 발견을 연다(강의 금지).
  예) `윤아: "잠깐, 하나씩 보자. 선풍기는 뭘 받고 움직이지?"` — 버튼·센서·
  사용 기록의 차이가 대사 속에서 드러나게.
- 장면4 [배턴 터치 — 해결 금지]: 현재의 '지도 완성' 결말 삭제. 마지막 줄 취지:
  `아이미: "그럼 저는 어느 쪽인가요? 세 도구 중 AI가 쓰인 건 무엇일까요?"`
  label·alt를 미해결형으로 조정(이미지는 지도 그림 그대로 — '빈 지도를 함께
  채우자' 프레임).

## 5. 선택지 반응 (각 choice에 `reaction` 추가)
firstAttempt:
- (정) 입력·결과 확인 — 윤아가 반기는 반응. 예) `윤아: "그거야. 받는 정보부터 보면 헷갈리지 않아."`
- (정) 입력별 처리 구분 — 아이미가 "제 입력은 글과 말이에요!"라고 거드는 반응.
- (오) 자동이면 AI — 자동문이 그저 센서로 열리는 장면을 윤아가 가리키는 반응.
- (오) 모양·이름으로 판단 — 진우가 "이름만 보고 샀다가 후회한 적 있잖아…"라고
  머쓱해하는 반응.
transfer(스마트 조명): 같은 요령으로 4개 — 정답은 기능 구분을 확인해 주고,
오답은 '겉모습/무조건 AI' 판단의 결과를 인물이 짧게 보여 준다.
