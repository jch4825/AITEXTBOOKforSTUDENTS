# AI 교과서 교사 가이드

현재 교과서는 6개 단원 68차시로 구성됩니다. 단원 마무리 전 62차시는 같은 8단계 경험
스튜디오이며, 각 단원의 마지막 6차시는 성장 포트폴리오입니다.

## 수업 흐름

1. 상황 만나기
2. 첫 생각 표현하기
3. 조건이 달라진 상황 살펴보기
4. 준비된 AI 예시와 비교하기
5. 내 판단 정하기
6. 생각을 결과물로 만들기
7. 다른 상황에 적용하기
8. 과정 돌아보기

정답률만 보지 말고 중요한 정보 찾기, 스스로 시도하기, AI 의견과 비교하기, 조건에 맞게
조정하기를 함께 관찰합니다.

## 지원 수준

| 화면 표시 | 내부 값 | 운영 방법 |
|---|---|---|
| 충분한 지원 | `full` | 정보와 선택지를 줄이고 힌트를 충분히 제공합니다. |
| 중학 | `light` | 기본 정보와 선택지를 제공하며 9학년군 성취기준으로 평가합니다. |
| 고등 | `challenge` | 비교와 이유 말하기의 깊이를 높이고 12학년군 성취기준으로 평가합니다. |

TTS와 AAC 카드 등 필요한 지원을 함께 사용할 수 있습니다. 주요 활동은 카메라·마이크 권한
없이 진행됩니다.

## 준비된 AI 예시와 AI 연결

62개 스튜디오는 수업 중단을 막기 위해 준비된 AI 예시를 사용합니다. 학생은 예시를 그대로
따르는 대신 자신의 생각과 비교하고, 사용할지·고칠지·다시 물을지 판단합니다.

교사 모드의 `AI 연결` 탭은 교사만 사용합니다. API 키와 모델 정보는 학생 화면에 보여 주지
않습니다. 키는 해당 브라우저에만 저장하며 백업 파일에는 포함하지 않습니다.

## 과정 기록과 개인정보

- 과정 기록은 교사가 켠 경우에만 같은 브라우저에 저장됩니다.
- 학생 별칭, 선택 결과, 지원 수준, 교사 관찰 기록을 저장합니다.
- 원본 음성·사진·그림과 전체 AI 대화는 저장하지 않습니다.
- 한 기기를 여러 학생이 사용하면 수업 전 별칭을 확인합니다.
- 교사 모드의 데이터 관리에서 개별/전체 삭제와 AES-GCM 암호화 백업·복원을 할 수 있습니다.

## 교사 모드

주소에 `?teacher=1`을 붙이고 교사 비밀번호로 들어갑니다.

- 운영 안내
- 학생 기록
- 포트폴리오
- AI 연결
- 교육과정·성취기준
- 연계 성취기준
- 데이터 관리

비밀번호는 학생 화면과 교사 화면을 나누는 장치이며 데이터 자체를 암호화하는 수단은 아닙니다.

## 수업 전 점검

1. 학생 별칭과 과정 기록 사용 여부
2. 사용할 지원 수준
3. TTS, 기기 음량, AAC 카드
4. 오늘 차시의 이야기 이미지 표시
5. 필요한 경우에만 교사 영역의 AI 연결 상태

오류가 나더라도 학생에게는 짧고 부드러운 안내를 제공하고, 기술 상세는 교사 영역에서 확인합니다.
